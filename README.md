A fully responsive, multi-section e-commerce frontend interface for a grocery store. Built during my 3rd semester, this project demonstrates advanced CSS layout techniques, interactive DOM manipulation, and the integration of third-party slider libraries to create a modern shopping experience.

**🔗 [View Live Demo](https://kumarhimanshu3132.github.io/grocery-website/)**

## ✨ Key Features
*   **Responsive Architecture:** Utilizes CSS Grid (`auto-fit`, `minmax`) and Flexbox alongside media queries to ensure a seamless UI across desktop, tablet, and mobile devices.
*   **Interactive UI Components:** Features a custom-built shopping cart sidebar, login modal, and mobile hamburger navigation menu, all toggled smoothly via Vanilla JavaScript.
*   **Touch-Friendly Carousels:** Integrates [Swiper.js](https://swiperjs.com/) for fluid, swipeable product and review sliders configured with responsive breakpoints.
*   **Modern CSS Styling:** Employs CSS Variables (`:root`) for strict color theming, custom CSS clip-paths for dynamic headers, and FontAwesome icons for visual hierarchy.

## 🛠️ Tech Stack
*   **Markup & Styling:** HTML5, CSS3
*   **Logic:** Vanilla JavaScript (ES6+)
*   **Libraries:** Swiper.js (Carousels), FontAwesome 4.7 (Icons)
*   **Typography:** Google Fonts (Poppins)

## 🚀 Local Setup Instructions

Since this is a client-side frontend application, running it locally requires no build tools, package managers, or local servers.

Clone the repository:
```bash
git clone https://github.com/kumarhimanshu3132/grocery-website.git
```

Navigate into the project directory:
```bash
cd grocery-website
```
Open the index.html file directly in any modern web browser.
